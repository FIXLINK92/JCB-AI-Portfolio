# Portfolio Security Rules

This portfolio must remain free of credentials, private keys, tokens, production environment files, customer data, confidential company records, and security-sensitive implementation details.

Before publishing any screenshot or code sample:

- remove secrets and personal data
- use synthetic/test records where possible
- review browser tabs, terminal output, URLs, headers, and environment variables visible in the capture
- do not publish private repository source unless it has been deliberately sanitized and approved for release
